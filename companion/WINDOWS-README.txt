AFTERGLOW 0.2

Extract the whole ZIP into one folder and run Afterglow.exe.
Keep flutter_windows.dll, the plugin DLLs and data/ beside the executable.
Requires Windows 10 1809+ / Windows 11 (x64) and the Microsoft Visual C++
2015-2022 x64 runtime: https://aka.ms/vs/17/release/vc_redist.x64.exe

Start music in a player with Windows media controls, then open Afterglow.
Enable audio reaction to analyze the current output through WASAPI loopback.
No microphone source, recording file or audio upload is used.

Desktop glow passes clicks through to your desktop.
CTRL + ALT + G returns to controls. In fullscreen, ESC returns and SPACE pauses.
If that global shortcut is already registered, overlay mode will refuse to start.
The overlay follows the monitor containing the controls when you start it.

Demo uses original fixture lyrics and a simulated envelope; it plays no audio.
Import LRC / TTML for exact supplied timings. Line timing is labeled estimated.
Some players omit metadata, duration or transport controls.
The fisheye renderer differs from the Linux OpenGL version.

This portable release is not code-signed. No administrator access is required.
Do not remove your Windows security protections to run software you do not trust.
